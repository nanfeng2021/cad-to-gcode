## 🚀 快速开始

### 安装依赖
```bash
cd /mnt/g/projects/cad-to-gcode

# Python 依赖
pip install -r requirements.txt

# 前端依赖 (可选)
cd src/web/vue-app
npm install
```

### 运行特征识别
```bash
# 生成训练数据
python src/ai/train_feature_model.py --samples-per-class 200

# 测试识别
python -c "
from src.ai.feature_recognition import FeatureRecognizer
recognizer = FeatureRecognizer(enable_ml=False)
print('特征识别引擎就绪')
"
```

### 运行刀路仿真
```bash
# 测试仿真
python src/cam/toolpath_simulation.py

# 或使用 API
python -c "
from src.cam.toolpath_simulation import simulate_gcode
gcode = 'G00 X50 Z0\nG01 Z-30 F200'
result = simulate_gcode(gcode, visualize=False)
print(f'加工时间：{result.total_time:.2f}s')
"
```

### 部署生产环境
```bash
# 运行部署脚本
bash scripts/deploy.sh

# 或手动部署
cd src/web/vue-app
npm run build
cp -r dist/* ../static/

# 启动服务
cd /mnt/g/projects/cad-to-gcode
uvicorn src.web.api:app --host 0.0.0.0 --port 8000
```

### 运行集成测试
```bash
python scripts/test_all_features.py
```

## 🐛 已知问题

### 高优先级
1. **前端未完全集成**
   - npm install 超时问题
   - 需要手动构建前端
   - 解决方案：使用部署脚本或手动构建

2. **API 测试失败**
   - 服务器启动延迟导致测试超时
   - 解决方案：手动测试或增加等待时间

### 中优先级
3. **ML 模型未训练**
   - 当前使用纯规则引擎
   - 需要收集训练数据
   - 下一步：生成数据集并训练

4. **2D 可视化限制**
   - 暂不支持 3D 材料去除
   - 需要 Three.js 或 Plotly
   - 下一步：集成 Plotly 3D

### 低优先级
5. **圆弧插补简化**
   - G02/G03 按直线近似
   - 需要精确圆弧计算
   - 影响：小，可接受
